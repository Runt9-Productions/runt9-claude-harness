# CLAUDE.md fragments

Each `.md` file here is a `fragment:<name>` component of `bootstrap.py`: always-on rules that `~/.claude/CLAUDE.md`
imports from `~/.claude/harness/current/fragments/`, as the root README's components table describes.

| Fragment | What it adds |
|---|---|
| `delegation` | When to hand work to a teammate, how many to run, and what stays with the lead. |
| `reasoning` | How claims get checked: the whole code path both ways, intent from the web, and doubt of a surprising result. |
| `security` | Hard limits: hooks always run, no reading credential stores, and no installs, downloads, remote connections or destroyed git history without the user asking. |
| `voice` | How replies read: plain, skeptical, concise, no dash splices, and a correction that says why the mistake happened. |
| `working-agreement` | When files may change, where generated documents go, asking rather than assuming, and how work is staged and reported. |
